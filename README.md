# Retail Sales Analytics Dashboard

**[Click here to open my Retail Sales Dashboard](https://retail-sales-dashboard-a6n3vfhanpm8kcthpbjkqz.streamlit.app/)**

- Python
- Streamlit
- Pandas
- Plotly

## Features
- Interactive sales and profit analysis
- Sales analysis by category and region
- Monthly sales trends
- Product performance analysis
- Interactive filters
